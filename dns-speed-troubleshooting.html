改 DNS 真的會變快嗎？先分清楚找網站慢，還是下載慢

Wilson說給你聽　｜　文章整理 2026.11.14　｜　約 6–8 分鐘

原片發布 2020-09-30 · 點封面看原片。

輸入網址後轉了好久，朋友說「把 DNS 換成 Google 的就好」。這個方法有時值得測，但先分清楚：是找網站的過程在等，還是連上後傳資料很慢？這兩種慢，排查方向不一樣。

這篇延伸自 2020 年的 DNS 主題影片，搭配官方文件整理。公開說明提出了「哪個 DNS 適合自己」的問題；下面用能回復、可比較的方式測試，不把任何一組公共 DNS 當成所有網路通用的加速器。

這篇會聊
  1. 按下網址後，要先找到對方
  2. 換 DNS 可能改善什麼，又改不了什麼
  3. 先在一台裝置測，別一次改全家
  4. 路由器、手機和瀏覽器，設定可能各走各的
  5. 開網站有差，下載沒變，怎麼看結果
  6. 換完出問題，照原本的記錄回復

按下網址後，要先找到對方

DNS 會把網站名稱解析成連線需要的資料，例如 IP 位址。電腦或瀏覽器也可能已快取答案，不一定每次開同一個網站都重新問一次。頁面載入中還有建立連線、伺服器回應與下載資源等步驟，不能只看轉圈圈就確認是 DNS。

你可以先記下哪些網站容易卡、第一次開和再次開有沒有差別、其他裝置是否也發生。想進一步量測時，再用系統的名稱查詢工具或瀏覽器開發者工具查看相關資訊。一般 ping 的往返時間，不能直接拿來當 DNS 查詢時間。

換 DNS 可能改善什麼，又改不了什麼

換解析器可能改變查詢延遲、可靠性，或網站回傳的 CDN 位置，所以使用感受有可能改變。效果依你的位置、網路、解析器和網站而不同，也可能變差。單次比較得到的結果，並不是哪個服務永遠最快的證明。

它不會把原本的寬頻方案變成更大的頻寬，也不能修好房間的弱訊號。有些下載服務可能因解析到不同節點而出現差異，但這不等於 DNS 本身替整條線路加速。先看原來卡在哪個環節，才知道變更是否切中問題。

先在一台裝置測，別一次改全家

先記錄這台裝置原本是自動取得 DNS，還是填了特定位址，最好留下完整畫面。從自己能管理的一台裝置開始測，比直接改全家路由器容易比對，也比較容易回復；先確認其他人不會受到這次測試影響。

Google Public DNS 的 IPv4 位址是 8.8.8.8 與 8.8.4.4，可作為官方可查的設定例子，並不代表一定比業者提供的解析器快。依裝置版本的官方方式修改，再用原本有問題的網站比較，不要把陌生文章裡的每個參數一起照抄。

  1. 記錄原本自動或手動設定，以及使用哪個網路。
  2. 只在一台自己管理的裝置上測試一組明確來源的 DNS。
  3. 用相同網站與用途比較，再決定保留或回復。

路由器、手機和瀏覽器，設定可能各走各的

同一個家裡，解析設定可能不只一層。路由器可以提供 DNS 資訊，但手機私人 DNS、瀏覽器安全 DNS 或 VPN，可能另外安排查詢路徑。改完路由器後某支手機沒有變化，不足以證明設定一定沒有儲存。

測試前先看看裝置和應用程式正在使用哪種方式，不要為了讓數字變漂亮就隨便停掉安全功能。公司 VPN 或內部服務也可能需要指定解析方式；若工作資源突然找不到，先回復自己的變更，再依組織的指引處理。

  1. 查看目前裝置是否啟用私人 DNS、瀏覽器安全 DNS 或 VPN。
  2. 確認本次修改影響的是系統、瀏覽器，還是路由器。
  3. 保留既有工作網路的要求，不把家用測試直接搬到公司環境。

開網站有差，下載沒變，怎麼看結果

如果網站開啟體感變好、下載最高速度沒變，這可能符合只改善部分載入流程的情況，但還不能只憑體感確認原因。網站快取、測試時段和伺服器負載也會改變結果。用同一個用途重複觀察，比抓一張最好的數字更有參考價值。

瀏覽器開發者工具有時能顯示 DNS 查詢階段，但既有連線和快取會影響你看見的資料；清除網頁檔案快取，也不等於清除了所有 DNS 快取。若整個家都慢，還是要回頭比較有線、路由器附近和真正會卡的位置，別只盯著 DNS。

換完出問題，照原本的記錄回復

若換完出現新的問題，照記錄恢復 DNS 原本的自動或手動設定，不是把整張網卡的 IP 配置全部改掉。裝置可能需要重新取得網路參數，依系統和路由器文件操作；不必一開始就把所有設備恢復原廠。

回復後再測原本的網站與工作服務。如果問題持續，把修改前後的現象、裝置和網路記下來，協助業者或管理者排查。DNS 是其中一個環節，先保留可比較的證據，會比不斷輪換一長串伺服器位址有效。

你可能還想問

改 DNS 就會匿名嗎？

不會。一般名稱解析、加密 DNS 與 VPN 是不同功能，不能把換解析器當成整條連線的匿名或加密保證。

為什麼手機和電腦測起來不一樣？

它們可能使用不同解析設定、快取或 VPN，也可能本來就有不同連線條件。先確認各自使用的路徑，再比較同一服務。

改完一定要重開路由器嗎？

依機型與修改位置而定。有時只需套用設定或讓裝置重新取得參數；先看官方流程，避免不必要地中斷全家網路。

可以先做這件事

先留下原設定，在一台裝置上用同一個網站比較；沒有改善，就回復並繼續查其他環節。
